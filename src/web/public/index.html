🔐 Garde ton SESSION_ID secret

Il donne accès à ton WhatsApp. Ne le partage jamais et ne le mets jamais dans le code sur GitHub.

Mot de passe administrateur

C'est la valeur de la variable ADMIN_PASSWORD que tu as définie sur Render.

WhatsApp connecté

  1. Sur Render, ouvre ton service → Environment.
  2. Colle la valeur dans la variable SESSION_ID puis Save changes.
  3. Le bot se reconnectera tout seul après chaque redémarrage.

Pour afficher ton SESSION_ID ou déconnecter le bot depuis ce site, ajoute la variable ADMIN_PASSWORD sur Render. Tu peux aussi envoyer .session dans ta discussion avec toi-même.

Sur WhatsApp, envoie .menu dans ta discussion avec toi-même (« Moi ») pour voir toutes les options.

Comment ça marche

Le trajet d'un message, pas à pas

Clique sur un bloc pour comprendre son rôle, ou lance la simulation.

  1. 1Un contact t'écrit

    Le message arrive sur ton téléphone… et sur le bot, connecté comme un appareil WhatsApp Web.

  2. 2Le bot trie

    Commande du propriétaire ? IA active ici ? Groupe : mention obligatoire ? Mode .meai : il attend le délai.

  3. 3L'IA réfléchit

    Le modèle NVIDIA reçoit la conversation récente (mémoire), ta personnalité, tes consignes et la description des images.

  4. 4La réponse part

    Découpée en plusieurs messages si elle est longue, avec fichiers joints si besoin. ⚙️ s'affiche pendant qu'elle écrit.

💾 Garder la mémoire

            
Sur Render gratuit, le disque est effacé à chaque redémarrage. Un cluster MongoDB Atlas M0 gratuit garde réglages, discussions actives et mémoire : ajoute MONGODB_URI.

          

          

            
😴 Rester éveillé

            
Le bot se rend visite toutes les 10 minutes. Pour plus de sûreté : une sonde UptimeRobot sur /health toutes les 5 minutes.

          

          

            
🍪 YouTube bloque ?

            
Exporte tes cookies YouTube au format cookies.txt et ajoute-les en Secret File sur Render (ou dans YT_COOKIES).

          

        

      

    

  


  
  

    

      

        
FAQ & dépannage

        
Une question ? La réponse est ici.

      

      

        
« Code incorrect » dans WhatsApp
Le code expire vite (environ 3 minutes) : redemande un code et saisis-le tout de suite. Vérifie le numéro : indicatif du pays, sans le 0 du début. L'aperçu sous le champ montre exactement ce qui est envoyé.

        
Le statut affiche « Déconnecté »
L'appareil a été retiré dans WhatsApp : refais l'appairage puis remplace SESSION_ID sur Render.

        
Le statut affiche « Ouvert ailleurs »
Le même SESSION_ID tourne à deux endroits (autre service, ton PC…) : n'en garde qu'un seul.

        
L'IA ne répond pas
Vérifie NVIDIA_API_KEY (le diagnostic en haut de page t'indique si elle est présente), puis teste avec .test. Les erreurs arrivent dans ta discussion « Moi ».

        
« Active d'abord .ai ou .meai »
.aai a besoin que .ai ou .meai soit déjà actif dans la discussion.

        
Modèle indisponible (erreur 404) ou erreur 429
404 : choisis un autre modèle avec .models. 429 : trop de requêtes pour ta clé NVIDIA, patiente ou augmente le délai avec .delai.

        
Mes réglages disparaissent après un redémarrage
Normal sans base de données : le disque gratuit de Render est effacé à chaque redémarrage. Réactive .ai / .meai / .aai, ou ajoute MONGODB_URI pour tout garder.

        
.song / .video ne marchent pas
« YouTube bloque le serveur » : ajoute tes cookies YouTube. « Aucun format » ou erreur 403 : yt-dlp se met à jour chaque jour, redéploie pour forcer la dernière version. Fichier trop lourd : augmente MEDIA_MAX_MB, SONG_MAX_MINUTES ou VIDEO_MAX_MINUTES.

        
Est-ce officiel ? Est-ce que je risque quelque chose ?
Le bot utilise Baileys, une bibliothèque WhatsApp Web non officielle, ni fournie ni approuvée par WhatsApp/Meta. Une utilisation abusive (spam, envois en masse) peut faire bannir ton numéro. Garde-le pour un usage personnel et préviens tes proches qu'une IA peut leur répondre.

        
Qui peut utiliser les commandes ?
Seuls tes messages sont lus comme des commandes. Exception : .song et .video, que tes contacts et les membres d'un groupe peuvent utiliser.
