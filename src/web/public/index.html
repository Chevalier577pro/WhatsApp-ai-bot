🔒 Mot de passe administrateur

C'est la valeur de la variable ADMIN_PASSWORD que tu as définie sur Render.

✅ WhatsApp connecté

  1. Sur Render, ouvre ton service → Environment.
  2. Colle la valeur dans la variable SESSION_ID puis Save changes.
  3. Le bot se reconnectera tout seul après chaque redémarrage.

Pour afficher ton SESSION_ID ou déconnecter le bot depuis ce site, ajoute la variable ADMIN_PASSWORD sur Render. Tu peux aussi envoyer .session dans ta discussion avec toi-même.

Sur WhatsApp, envoie .menu dans ta discussion avec toi-même (« Moi ») pour voir toutes les options.

Connexion avec un code

----
  1. Ouvre WhatsApp sur ton téléphone.
  2. Réglages (ou ⋮) → Appareils connectés → Connecter un appareil.
  3. Touche Connecter avec un numéro de téléphone.
  4. Saisis le code ci-dessus. Le bot se connecte tout seul.

Connexion avec un QR code

Pratique si ce site est ouvert sur un ordinateur : WhatsApp → Appareils connectés → Connecter un appareil, puis scanne le QR.
